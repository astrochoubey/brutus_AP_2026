# PostgreSQL EXPLAIN Execution Plan: Query 6 (Scan Audit & Data Quality)

## Query
```sql
SELECT 
    sc.scan_id,
    sc.scan_type,
    ss.status_label,
    ss.is_valid_for_analysis,
    sc.reported_count,
    sc.collected_count,
    (sc.reported_count - sc.collected_count) AS missing_count,
    sc.duplicate_count,
    sc.error_count,
    ROUND(sc.confidence_score, 2) AS confidence_score,
    sc.started_at,
    sc.completed_at
FROM scans sc
JOIN scan_statuses ss ON sc.status_code = ss.status_code
WHERE sc.observer_id = 'obs_default'
ORDER BY sc.started_at DESC;
```
