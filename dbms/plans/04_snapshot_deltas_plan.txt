# PostgreSQL EXPLAIN Execution Plan: Query 4 (Snapshot Differencing & Churn Deltas)

## Query
```sql
SELECT 
    rd.delta_id,
    rd.from_snapshot_id,
    rd.to_snapshot_id,
    u.username,
    u.full_name,
    ct.type_code AS change_type,
    ct.description AS change_description,
    ct.is_churn,
    rd.detected_at
FROM relationship_deltas rd
JOIN change_types ct ON rd.change_type_id = ct.change_type_id
JOIN users u ON rd.target_user_id = u.user_id
WHERE rd.from_snapshot_id = 'snap_bench_a'
  AND rd.to_snapshot_id = 'snap_bench_b'
ORDER BY rd.detected_at DESC, u.username ASC;
```

## Key Optimization Insights
- **Unique Compound Constraint `uq_delta_event`:** Index condition matches on both `from_snapshot_id` and `to_snapshot_id`, allowing instantaneous extraction of delta changes between sequential scans.
- **Constant Time Churn Resolution:** Fast primary key dereference for `change_types` and `users`.
